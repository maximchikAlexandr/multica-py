## 1. Execution contracts and `LocalExecutor`; `CliTransport`/`ManagedProcess` refactor

- [ ] 1.1 Create the provider-independent contracts: immutable `ExecutionRequest` and `ExecutionResult`; `ProcessHandle` with `id`, `poll`, `wait`, `collect`, `terminate`, `kill`, line iterators, and `close`; and `CommandExecutor` with `run`, `spawn`, `stage(label, content) -> ContextManager[str]`, and `close`. Add only `ExecutionError`, `ExecutionConnectionError`, `ExecutionTargetNotFoundError`, and `ExecutionUnavailableError`; reachable-target executable failures use the existing public executable errors. Keep buffered and streaming output mutually exclusive. No provider fields or `Any`.
- [ ] 1.2 Create stdlib-only `LocalExecutor` around the existing process helpers. Preserve local environment inheritance and process behavior. Implement staging with `contextlib.contextmanager` and `TemporaryDirectory`. Re-export only common contracts, execution exceptions, and `LocalExecutor` from `multica_py.execution`; optional providers remain in their submodules.
- [ ] 1.3 Refactor `src/multica_py/process.py` `ManagedProcess` to wrap a `ProcessHandle` instead of `subprocess.Popen` directly. Preserve the output-claim state machine (buffered/streaming/discarded) and semaphore release. `.id` exposes the handle's `id`. `.pid` returns the handle's `id` when it is an `int`, else `None`. `result()` routes through `handle.collect()` (buffered); `stdout_lines`/`stderr_lines` route through the handle. `collect` and the line iterators are mutually exclusive — calling `result()` after streaming raises `RuntimeError`.
- [ ] 1.4 Refactor `CliTransport` to build `ExecutionRequest` and delegate to the executor. Requests contain explicit environment overrides only; preview redaction keeps the existing conservative `_effective_environment(config)` input without adding an executor method. Preserve compatibility, decode, redaction, semaphore, and existing CLI error classification. Re-raise execution errors unchanged; executable failures already use the existing public classes.
- [ ] 1.5 Keep cwd/executable APIs compatible with `str | os.PathLike`. Convert with `os.fspath()` without `pathlib`, resolution, or controller validation; document that remote paths SHOULD be strings. Test verbatim POSIX-path passthrough on a simulated Windows controller and continued local `Path` acceptance.
- [ ] 1.6 Add one table-driven executor-conformance suite over provider-neutral factories for exact argv/cwd/environment/stdin/timeout, byte-exact result mapping, run, non-PTY spawn, poll/wait, collect/stream single ownership, opaque identity, staging/cleanup, error mapping, and non-destructive close. Add providers as case rows; keep provider-only protocol/auth/serialization/process-control tests separate. Also cover local byte-for-byte behavior.
- [ ] 1.7 Run focused execution, transport, component fake-CLI, and process-lifecycle tests; compare ordinary-command behavior with the baseline and verify path-like upload byte/result parity through staging.
